HTML & CSS Quick Reference

A concise guide covering core tags and properties used in modern web projects — clean examples, no clutter.

Document foundation

<!DOCTYPE> and <html>

<!DOCTYPE html> activates modern HTML5 standards. The <html lang="en"> root wraps all content.

<!DOCTYPE html>
<html lang="en">
  <head>...</head>
  <body>...</body>
</html>

<head> & <body>

<head> holds meta-information, <title>, and linked styles. <body> contains visible content.

<head>
  <meta charset="UTF-8">
  <title>Page title</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>Visible content</h1>
</body>

<meta> tags

Essential for responsiveness and character encoding.

<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta name="description" content="Quick reference guide">

Inline code snippet and preformatted blocks preserve spacing.

<pre><code>

  display: flex;
  gap: 1rem;
}
</code></pre>

CSS basics

Selectors

/* element selector */
p { color: navy; }
/* class selector */
.card { background: white; padding: 1rem; }
/* id selector */
#header { font-size: 2rem; }

Box model & box-sizing

.box {
  width: 200px;
  padding: 16px;
  border: 2px solid #ccc;
  margin: 24px;
  box-sizing: border-box;
}

Colors & typography

body {
  color: #1e1e1e;
  background-color: hsl(40, 20%, 97%);
  font-family: 'Georgia', serif;
  font-size: 1rem;
  line-height: 1.6;
  text-align: left;
}

Layout: display (flex & grid)

.flex-row {
  display: flex;
  justify-content: space-between;
  gap: 1rem;
}
.grid-three {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;
  gap: 1.5rem;
}

CSS Custom Properties (variables)

:root {
  --primary: #7f8c5e;
  --spacing: 1rem;
}
.card {
  background: var(--primary);
  padding: var(--spacing);
}

External stylesheets

<head>
  <link rel="stylesheet" href="styles.css">
</head>

Quick syntax reminders

<!-- comment in HTML -->
/* comment in CSS */

<div class="container">
  <p>block with padding and margin</p>
</div>
Note: Always use semantic elements when possible, and prefer CSS over deprecated tags like <center>. The box model with box-sizing: border-box makes layouts predictable.
